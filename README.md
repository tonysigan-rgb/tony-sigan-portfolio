# Tony Sigan Portfolio

A single-page, responsive portfolio ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository named `tony-sigan-portfolio`.
2. Upload or push this folder to its `main` branch.
3. In the repository, open **Settings → Pages** and choose **Deploy from a branch**.
4. Select `main` and the `/(root)` folder, then save.

Your free site will be available at `https://YOUR-GITHUB-USERNAME.github.io/tony-sigan-portfolio/` within a few minutes.
